## 1. Verdict: **FAIL**

这个 commit **不能放行 dense-equivalent claim，也不应直接放行正式长训作为 paper 主结果**。原因不是“有没有 Traceback”，而是：`f541715` 主要是在 sparse/bridge route 上加 axis contract、diagnostic-only、primary-result gate；它没有证明 bridge/head 已恢复官方 OpenTAD dense ActionFormer/AdaTAD 的监督合同、decode 合同和 postprocess 合同。该 commit 确实固定在 `f541715`，标题是 “Harden sparse route axis contracts”，变更集中在 route contract、配置、测试和 fail-closed 检查上，而不是一次核心检测头等价性重写。([GitHub][1])

更关键的是，当前多个 bridge 配置本身把 `dense_equivalent_claim_allowed=False`、`diagnostic_only=True`、`primary_result_allowed=False` 写进 route contract。也就是说，这些实验按配置语义只能作为诊断路线，不能作为主结果，也不能声称“等价官方 dense head”。([GitHub][1])

## 2. Top blockers

**Blocker 1：官方 dense contract 还没有被当前 repo 严格复现。**
官方 `AnchorFreeHead` 的核心合同是：`PointGenerator` 生成 `[center, reg_min, reg_max, stride]`，regression decode 用 `start=center-left*stride`、`end=center+right*stride`，训练 target 先用 center radius、regression range、shortest-GT assignment 选正样本，再把 GT distance 除以 stride。([GitHub][2]) 当前 bridge/head 改造用 native/selected irregular grid、cell span、absolute/open/level_stride range、不同 decode scale、不同 center-radius scale，这些都不是天然等价，只能逐项证明。

**Blocker 2：runtime 使用了 `postprocess_axis` 执行 NMS，route contract 里的 `nms_axis` 没有被 detector 独立读取。**
当前 `SingleStageDetector._postprocess_axes_from_meta()` 只返回 `proposal_axis, postprocess_axis`，post-processing 中先把 proposal 转到 `postprocess_axis`，然后直接 `batched_nms`。它没有读取或执行独立的 `nms_axis`。([GitHub][3]) `IrregularActionFormer` 也是从 meta 取 `gt_axis, proposal_axis, postprocess_axis`，随后把 segments 转到 `postprocess_axis` 后 NMS；`nms_axis` 只存在于配置/contract 层，没有成为 runtime contract。([GitHub][4]) 当前配置多数 `nms_axis=native, postprocess_axis=native`，所以未必直接造成这几组结果错误，但这是一个真实 contract hole：你以为 gate 检查了 NMS 轴，实际 runtime 没有。

**Blocker 3：`tools/check_fail_closed_config.py` 的 bridge route schema 检查有早退 bug。**
`scan_route_contract_object()` 对 bridge head 做了 legacy/dense-claim 检查后，在执行 `_scan_route_contract_schema()` 之前就 `return violations`；后面的 route contract schema、axis、diagnostic、compatibility 检查在 bridge 分支对非 legacy 正常路线是死代码。([GitHub][5]) 这意味着 f541715 的 fail-closed gate 没有你以为的强度。

**Blocker 4：`SingleStageDetector` 的 single-class score filtering 与 irregular detector 不一致。**
`SingleStageDetector.post_processing()` 在 `num_classes == 1` 时只 squeeze score 并赋零 label，没有执行 `pre_nms_thresh` 和 `pre_nms_topk`；multi-class 路径才做阈值和 top-k。([GitHub][3]) `IrregularActionFormer` 的 single-class 路径则做了 threshold 和 top-k。([GitHub][4]) THUMOS 主配置通常是 multi-class，所以这未必解释 40/42，但它是 confirmed logic bug，会污染 one-class/sanity 路线。

**Blocker 5：当前工具还不能解释 65 → 40/42。**
same-batch assignment audit 只能说明“这个 batch 上哪些点被分配为 positive、哪些 level 被 range gate 压死”，不能证明 final detector 的 pre-NMS recall、score calibration、NMS 删除行为、boundary precision 或全数据分布。现在最缺的是 proposal-level pre/post-NMS dump 和 target-decode IoU → trained-proposal IoU 的链路。

## 4. Suspicious but unproven risks

**Risk 1：openrange / absrange 恢复 positives，但改变了官方监督合同。**
官方 regression range 是由 `PointGenerator` 每层的 regression_range 和 stride 定义，center radius 也是 stride-based。([GitHub][2]) 当前 `IrregularPointGeneratorV2` 支持 `hard/absolute/open/level_stride/overlap_band`，还把 decode scale、range scale、radius scale 拆成不同字段。([GitHub][6]) 这很适合诊断，但不能直接声称“官方等价”。特别是 `openrange` 恢复 positives 只说明 range gate 不再杀正样本，不说明 target decode、训练梯度、score calibration 或 final proposal quality 正确。

**Risk 2：bridge target assignment “形似官方”，但 scale 语义不一定等价。**
bridge 的 `prepare_targets` 也做 left/right distance、center sampling、regression range、shortest-GT assignment，并支持 `filter_similar_gt`。([GitHub][7]) 但它的 point fields 是 `[center, reg_min, reg_max, left_scale, right_scale, point_scale, range_scale, radius_scale]`，decode 和 target encode 可以走 `symmetric_linear` 或 log-like 模式。([GitHub][7]) 只要 `center/range_scale/radius_scale/reg_denom` 任一项与官方 stride 语义不一致，就会出现“positives 看起来正常，但高 IoU proposal 上不去”。

**Risk 3：selected/native/seconds double conversion 未被完整排除。**
当前 `convert_to_seconds` 已经要求 `source_axis`，`source_axis="selected"` 时先 selected→native，再按 fps/snippet_stride/window_start 转秒；`source_axis="auto"` 对 selected metadata 默认拒绝，除非显式 legacy。([GitHub][8]) 这是好方向。但只靠这段不能证明 detector 中所有路径都正确传了 source axis，尤其是 debug dump、external classifier、sliding-window merge 和 legacy SingleStage path。

**Risk 4：pre-NMS 与 post-NMS 之间没有足够证据。**
官方 postprocess 在 THUMOS AdaTAD config 中使用 soft-NMS、`max_seg_num=2000`、`multiclass=True`、`voting_thresh=0.7`。([GitHub][9]) 当前 `IrregularActionFormer` 的 `debug_dump_proposals` 是 NMS 后才 dump；这不足以判断高质量 proposal 是训练没生成、score 太低被 pre-NMS top-k 删掉，还是 NMS/seg voting 删除或扭曲了。

## 5. Required analyses before paper claims

### A. same-batch assignment audit 能证明什么

它能证明：

1. 当前 batch、当前 GT、当前 selected/native grid 下，哪些 point 被分配为 positive。
2. regression range 是否把 positives 压到低层。
3. center sampling / fallback / openrange / absrange 是否改变 pos_by_level。
4. bridge 与某个“当前实现 dense head”在 target 统计上是否接近。

1. 官方 OpenTAD dense route 已复现。
2. final proposal 高 IoU 能力正确。
3. score calibration 正确。
4. NMS 没删掉高质量 proposal。
5. 多 batch、多 seed、多视频 duration bucket 上没有系统偏差。
6. 当前 repo 复制的 dense head 与官方 OpenTAD 完全一致。

## 6. Performance collapse root-cause ranking

### 1. **Feature geometry 与 native sparse label 不匹配**：最高优先级

证据：openrange 能恢复全层 positives，但 mAP 仍 42 左右。这说明“没有正样本”不是唯一问题。更可能是 selected sparse feature 的局部语义、FPN receptive field、point center、native distance target 之间不匹配。也就是说，head 在 native 时间轴上回归，但输入特征不是官方 dense grid 上的均匀特征。

确认实验：

```text
same video, same GT:
A. official dense feature grid + official head
B. dense feature grid + bridge official_compat mode
C. uniform selected feature grid + native-axis bridge
D. random selected feature grid + native-axis bridge
E. random selected feature grid + selected-axis bridge
比较 target-decode IoU、pre-NMS best IoU、post-NMS recall。
```

### 2. **regression range / scale / denominator 错误或非官方化**

已知原 bridge_hard_linear range 会把 positives 压死在 level0/1；openrange 修复 positives 但未恢复 mAP。这说明 range/scale 至少曾经是硬 bug，而且现在仍可能是“正样本数量恢复但 target 分布不对”。官方 target normalization 是除以 point stride。([GitHub][2]) 当前 bridge 可用 `reg_denom_mode`、`decode_scale_mode`、`range_scale`、`radius_scale`，必须逐项对齐。

确认实验：

```text
dense-equivalent tiny test:
official point = [center=8, stride=4], GT=[2,16]
official target = [(8-2)/4, (16-8)/4] = [1.5, 2.0]
bridge target 必须完全一致；
bridge decode(target) 必须回到 [2,16]。
```

### 3. **NMS / score calibration / high-quality proposal 被删除**

如果 pre-NMS best-IoU 高、post-NMS recall 低，则是 NMS/score 问题。当前缺 pre/post dump，无法排除。官方 batched NMS 会按 class 分组、soft-NMS 或 vanilla NMS、再全局排序截断。([GitHub][10]) sparse/native 坐标下 proposal 长度分布变化会改变 soft-NMS 抑制行为。

确认实验：

```text
pre-NMS recall@0.5/0.6/0.7
post-NMS recall@0.5/0.6/0.7
被 NMS 删除的 high-IoU proposal 的 suppressor score / suppressor IoU / class。
```

### 4. **selected/native/seconds axis 混杂**

f541715 已经加强了 `source_axis`，但 runtime 没独立读 `nms_axis`，所以 axis 还不能宣告完全安全。`convert_to_seconds` 本身比旧版更 fail-closed，但 detector 和 config contract 还没完全闭环。([GitHub][8])

### 5. **official dense baseline 未复现**

这个必须先排除。官方 AdaTAD THUMOS VideoMAE-S 768×1 config 是 768 帧、VideoMAE adapter、ActionFormer base，并在 README 给出 THUMOS results；你的 50% equal-interval 65 是改造 baseline，必须在 official repo 或 byte-equivalent route 上重新落账。([GitHub][9])

### 6. **random sparse 与 equal-interval 的本质差异**

这会造成退化，但不足以解释 65 → 40/42 的全部。因为你已有 random-fixed 50% 约 63 的历史结果；若 bridge/openrange 仍 42，问题更像 head/axis/geometry/postprocess 合同偏移，而不是 random sparse 自然退化。

    re.IGNORECASE,

TIOU_RE = re.compile(r"mAP@(?:tIoU=)?([0-9.]+)\s*[:=]\s*([0-9]+(?:\.[0-9]+)?)", re.IGNORECASE)


def sha256_file(path: Path) -> str:
    h = hashlib.sha256()
    with path.open("rb") as f:
        for chunk in iter(lambda: f.read(1 << 20), b""):
            h.update(chunk)
    return h.hexdigest()


def read_json_or_jsonl(path: Path) -> List[Dict[str, Any]]:
    if not path.exists():
        return []
    text = path.read_text(encoding="utf-8", errors="replace").strip()
    if not text:
        return []
    try:
        obj = json.loads(text)
        if isinstance(obj, list):
            return [x for x in obj if isinstance(x, dict)]
        if isinstance(obj, dict):
            return [obj]
    except json.JSONDecodeError:
        pass

    rows = []
    for line in text.splitlines():
        line = line.strip()
        if not line:
            continue
        try:
            obj = json.loads(line)
            if isinstance(obj, dict):
                rows.append(obj)
        except json.JSONDecodeError:
            continue
    return rows


def find_file(work_dir: Path, candidates: Iterable[str]) -> Optional[Path]:
    for name in candidates:
        p = work_dir / name
        if p.exists():
            return p
    for name in candidates:
        hits = list(work_dir.rglob(name))
        if hits:
            return hits[0]
    return None


def flatten_config_hint(config_text: str) -> Dict[str, Any]:
    keys = [
        "gt_axis",
        "proposal_axis",
        "nms_axis",
        "postprocess_axis",
        "eval_axis",
        "diagnostic_only",
        "primary_result_allowed",
        "dense_equivalent_claim_allowed",

        "radius_scale_mode",
        "dense_compat_mode",
        "assignment_mode",
        "regression_mode",
        "reg_denom_mode",
        "center_radius_scale",
    ]
    out = {}
    for key in keys:
        m = re.search(rf"{key}\s*=\s*([^,\n)]+)", config_text)
        if m:
            out[key] = m.group(1).strip().strip("'\"")
    return out


def parse_metrics_from_logs(log_rows: List[Dict[str, Any]], raw_text: str) -> Dict[str, Any]:
    out: Dict[str, Any] = {}
    for row in log_rows:
        for k, v in row.items():
            lk = str(k).lower()
            if "map" in lk and isinstance(v, (int, float)):
                out[k] = float(v)
    for name, value in MAP_RE.findall(raw_text):
        out["Average-mAP"] = float(value)
    for tiou, value in TIOU_RE.findall(raw_text):
        out[f"mAP@{float(tiou):.2f}"] = float(value)
    return out


def collect_one(work_dir: Path) -> Dict[str, Any]:
    row: Dict[str, Any] = {"work_dir": str(work_dir)}

    for p in text_logs:
        raw_log_text += "\n" + p.read_text(encoding="utf-8", errors="replace")

    result_path = find_file(work_dir, ["result_detection.json", "results_detection.json"])

        except Exception as exc:

    return row

#!/usr/bin/env python3

from __future__ import annotations

import argparse
import hashlib
import json
from pathlib import Path
from typing import Any, Dict, List

import torch


def tensor_hash(x: torch.Tensor) -> str:
    x_cpu = x.detach().cpu().contiguous()
    h = hashlib.sha256()
    h.update(str(tuple(x_cpu.shape)).encode())
    h.update(str(x_cpu.dtype).encode())
    h.update(x_cpu.numpy().tobytes())
    return h.hexdigest()


def segment_iou_1d(a: torch.Tensor, b: torch.Tensor) -> torch.Tensor:
    if a.numel() == 0 or b.numel() == 0:
        return a.new_zeros((a.shape[0], b.shape[0]))
    left = torch.maximum(a[:, None, 0], b[None, :, 0])
    right = torch.minimum(a[:, None, 1], b[None, :, 1])
    inter = (right - left).clamp_min(0)
    len_a = (a[:, 1] - a[:, 0]).clamp_min(1e-6)
    len_b = (b[:, 1] - b[:, 0]).clamp_min(1e-6)
    return inter / (len_a[:, None] + len_b[None, :] - inter).clamp_min(1e-6)


@torch.no_grad()
def audit_batch(model, batch: Dict[str, Any], out_handle) -> None:
    inputs = batch["inputs"]
    masks = batch["masks"]
    metas = batch["metas"]
    gt_segments = batch.get("gt_segments", [])
    gt_labels = batch.get("gt_labels", [])

    model.eval()
    model._assert_axis_contracts(metas, stage="audit")

    temporal_grids = model._temporal_grid_from_metas(metas, masks)
    x = model.backbone(inputs, metas=metas) if getattr(model, "with_backbone", False) else inputs
    x, pad_masks, temporal_grid = model.pad_data(x, masks, temporal_grids)
    feat_list, mask_list, temporal_grid_list = model._project_features(x, pad_masks, temporal_grid)

    points = model.rpn_head._generate_points(feat_list, temporal_grid_list)
    targets = model.rpn_head.prepare_targets(points, gt_segments, gt_labels)

    if len(targets) == 4:
        gt_cls, gt_reg, reg_weight, target_debug = targets
    else:
        gt_cls, gt_reg = targets
        reg_weight = [(c.sum(-1) > 0).to(c.dtype) for c in gt_cls]
        target_debug = {}

    level_offsets = model.rpn_head._level_offsets(points) if hasattr(model.rpn_head, "_level_offsets") else []
    point_tensor = model.rpn_head._concat_points(points) if hasattr(model.rpn_head, "_concat_points") else torch.cat(points, dim=0)

    for bi, meta in enumerate(metas):
        cls_i = gt_cls[bi].detach().cpu()
        reg_i = gt_reg[bi].detach().cpu()
        weight_i = reg_weight[bi].detach().cpu()
        pos_mask = cls_i.sum(-1) > 0

        gt_i = gt_segments[bi].detach().cpu()
        lab_i = gt_labels[bi].detach().cpu() if len(gt_labels) else torch.empty(0, dtype=torch.long)

        split_size = [p.shape[1] if p.dim() == 3 else p.shape[0] for p in points]
        gt_reg_split = reg_i.t().unsqueeze(0).split(split_size, dim=-1)
        decoded_targets = model.rpn_head.get_refined_proposals(points, list(gt_reg_split))[0].detach().cpu()

        ious = segment_iou_1d(decoded_targets[pos_mask], gt_i) if gt_i.numel() else torch.empty(0, 0)
        best_iou = ious.max(dim=1).values if ious.numel() else torch.empty(0)

        pos_by_level = []
        for start, end in level_offsets:
            pos_by_level.append(int(pos_mask[start:end].sum().item()))

        selected_positions = meta.get("irregular_selected_positions", [])
        selected_tensor = torch.as_tensor(selected_positions) if len(selected_positions) else torch.empty(0)

        record = {
            "video_name": meta.get("video_name", ""),
            "axis_contract": meta.get("irregular_axis_contract", {}),
            "irregular_native_axis": bool(meta.get("irregular_native_axis", False)),
            "gt_axis": meta.get("irregular_gt_axis"),
            "proposal_axis": meta.get("irregular_proposal_axis"),
            "nms_axis": meta.get("irregular_nms_axis"),
            "postprocess_axis": meta.get("irregular_postprocess_axis"),
            "fps": meta.get("fps"),
            "snippet_stride": meta.get("snippet_stride"),
            "offset_frames": meta.get("offset_frames"),
            "window_start_frame": meta.get("window_start_frame", 0),
            "mask_hash": tensor_hash(masks[bi].to(torch.uint8)),
            "gt_hash": tensor_hash(gt_i) if gt_i.numel() else "empty",
            "selected_positions_hash": tensor_hash(selected_tensor.float()) if selected_tensor.numel() else "empty",
            "selected_positions_head": selected_tensor[:16].tolist(),
            "selected_positions_tail": selected_tensor[-16:].tolist(),
            "num_gt": int(gt_i.shape[0]),
            "gt_segments": gt_i.tolist(),
            "gt_labels": lab_i.tolist(),
            "num_points": int(cls_i.shape[0]),
            "num_positive": int(pos_mask.sum().item()),
            "pos_by_level": pos_by_level,
            "target_decode_best_iou_mean": float(best_iou.mean().item()) if best_iou.numel() else None,
            "target_decode_best_iou_min": float(best_iou.min().item()) if best_iou.numel() else None,
            "target_decode_iou_ge_050": float((best_iou >= 0.50).float().mean().item()) if best_iou.numel() else None,
            "target_decode_iou_ge_070": float((best_iou >= 0.70).float().mean().item()) if best_iou.numel() else None,
            "target_debug": target_debug,
        }
        out_handle.write(json.dumps(record, ensure_ascii=False) + "\n")


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--config", required=True)
    ap.add_argument("--checkpoint", default=None)
    ap.add_argument("--out", required=True)
    ap.add_argument("--max-batches", type=int, default=20)
    args = ap.parse_args()

#!/usr/bin/env python3
# tools/diagnostics/analyze_prepost_detection_quality.py

from __future__ import annotations

import argparse
import csv
import json
from collections import defaultdict
from pathlib import Path
from typing import Any, Dict, Iterable, List, Tuple

import numpy as np


def iou_1d(a: Tuple[float, float], b: Tuple[float, float]) -> float:
    left = max(a[0], b[0])
    right = min(a[1], b[1])
    inter = max(0.0, right - left)
    la = max(1e-9, a[1] - a[0])
    lb = max(1e-9, b[1] - b[0])
    return inter / max(1e-9, la + lb - inter)


def load_jsonl(path: Path) -> List[Dict[str, Any]]:
    rows = []
    with path.open("r", encoding="utf-8") as f:
        for line in f:
            if line.strip():
                rows.append(json.loads(line))
    return rows


def load_gt(path: Path) -> Dict[str, List[Dict[str, Any]]]:
    obj = json.loads(path.read_text(encoding="utf-8"))
    db = obj.get("database", obj)
    out = {}
    for vid, item in db.items():
        anns = item.get("annotations", item if isinstance(item, list) else [])
        out[vid] = [
            {
                "segment": ann["segment"],
                "label": ann.get("label", ann.get("class", ann.get("label_id"))),
            }
            for ann in anns
        ]
    return out


def annotate_best_gt(pred: Dict[str, Any], gts: List[Dict[str, Any]]) -> Dict[str, Any]:
    seg = tuple(float(x) for x in pred["segment_seconds"])
    label = pred.get("label", pred.get("class_id"))
    best_any = 0.0
    best_same = 0.0
    best_same_gt = None
    for gi, gt in enumerate(gts):
        gt_seg = tuple(float(x) for x in gt["segment"])
        val = iou_1d(seg, gt_seg)
        best_any = max(best_any, val)
        if str(gt.get("label")) == str(label):
            if val > best_same:
                best_same = val
                best_same_gt = (gi, gt)
    pred = dict(pred)
    pred["best_iou_any_class"] = best_any
    pred["best_iou_same_class"] = best_same
    if best_same_gt is not None:
        _, gt = best_same_gt
        gs, ge = gt["segment"]
        ps, pe = seg
        pred["start_error"] = ps - gs
        pred["end_error"] = pe - ge
        pred["center_error"] = 0.5 * (ps + pe) - 0.5 * (gs + ge)
        pred["duration_ratio_error"] = ((pe - ps) / max(1e-9, ge - gs)) - 1.0
    else:
        pred["start_error"] = pred["end_error"] = pred["center_error"] = pred["duration_ratio_error"] = None
    return pred


def infer_nms_drop_reasons(pre_rows: List[Dict[str, Any]], post_rows: List[Dict[str, Any]], nms_iou_thr: float) -> List[Dict[str, Any]]:
    kept_keys = set()
    for r in post_rows:
        kept_keys.add((r["video_name"], int(r["label"]), round(float(r["score"]), 6),
                       tuple(round(float(x), 4) for x in r["segment_seconds"])))

    post_by_video_label = defaultdict(list)
    for r in post_rows:
        post_by_video_label[(r["video_name"], int(r["label"]))].append(r)

    out = []
    for r in pre_rows:
        key = (r["video_name"], int(r["label"]), round(float(r["score"]), 6),
               tuple(round(float(x), 4) for x in r["segment_seconds"]))
        rr = dict(r)
        rr["was_kept_by_nms"] = key in kept_keys
        rr["nms_drop_reason"] = None
        rr["suppressor_score"] = None
        rr["suppressor_iou"] = None

        if not rr["was_kept_by_nms"]:
            candidates = post_by_video_label.get((r["video_name"], int(r["label"])), [])
            suppressors = []
            for k in candidates:
                ov = iou_1d(tuple(r["segment_seconds"]), tuple(k["segment_seconds"]))
                if ov >= nms_iou_thr and float(k["score"]) >= float(r["score"]):
                    suppressors.append((ov, float(k["score"]), k))
            if suppressors:
                suppressors.sort(key=lambda x: (x[1], x[0]), reverse=True)
                ov, sc, _ = suppressors[0]
                rr["nms_drop_reason"] = "suppressed_by_higher_score_overlap"
                rr["suppressor_score"] = sc
                rr["suppressor_iou"] = ov
            else:
                rr["nms_drop_reason"] = "missing_after_nms_or_voting_or_topk"
        out.append(rr)
    return out


def summarize(rows: List[Dict[str, Any]], stage: str) -> Dict[str, Any]:
    out = {"stage": stage, "num_predictions": len(rows)}
    for thr in [0.3, 0.4, 0.5, 0.6, 0.7]:
        out[f"recall_proxy_iou_ge_{thr:.1f}"] = float(np.mean([r["best_iou_same_class"] >= thr for r in rows])) if rows else 0.0
    if rows:
        out["mean_best_iou_same_class"] = float(np.mean([r["best_iou_same_class"] for r in rows]))
        out["mean_score"] = float(np.mean([float(r["score"]) for r in rows]))
    return out


def write_csv(rows: List[Dict[str, Any]], path: Path) -> None:
    keys = sorted(set().union(*(r.keys() for r in rows))) if rows else []
    with path.open("w", newline="", encoding="utf-8") as f:
        w = csv.DictWriter(f, fieldnames=keys)
        w.writeheader()
        w.writerows(rows)


def main() -> int:
    ap = argparse.ArgumentParser()
    ap.add_argument("--gt", required=True)
    ap.add_argument("--pre-nms-jsonl", required=True)
    ap.add_argument("--post-nms-jsonl", required=True)
    ap.add_argument("--out-prefix", required=True)
    ap.add_argument("--nms-iou-thr", type=float, default=0.6)
    args = ap.parse_args()

    gt = load_gt(Path(args.gt))
    pre = load_jsonl(Path(args.pre_nms_jsonl))
    post = load_jsonl(Path(args.post_nms_jsonl))

    pre_ann = [annotate_best_gt(r, gt.get(r["video_name"], [])) for r in pre]
    post_ann = [annotate_best_gt(r, gt.get(r["video_name"], [])) for r in post]
    drop_ann = infer_nms_drop_reasons(pre_ann, post_ann, args.nms_iou_thr)

    prefix = Path(args.out_prefix)
    prefix.parent.mkdir(parents=True, exist_ok=True)
    write_csv(pre_ann, prefix.with_suffix(".pre_nms.csv"))
    write_csv(post_ann, prefix.with_suffix(".post_nms.csv"))
    write_csv(drop_ann, prefix.with_suffix(".nms_drop.csv"))

    summary = {
        "pre_nms": summarize(pre_ann, "pre_nms"),
        "post_nms": summarize(post_ann, "post_nms"),
        "num_high_iou_dropped_07": int(sum((not r["was_kept_by_nms"]) and r["best_iou_same_class"] >= 0.7 for r in drop_ann)),
    }
    prefix.with_suffix(".summary.json").write_text(json.dumps(summary, indent=2), encoding="utf-8")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

## 10. Final recommended route to recover performance

不要继续在 openrange/absrange 上盲目长训。下一步应该按这个顺序恢复：

1. **先修 gate 和 runtime contract**：修 scanner 早退；让 runtime 显式处理 `nms_axis`；修 SingleStage single-class filtering。
2. **建立 official dense reference**：官方 OpenTAD 固定 commit + 官方 THUMOS AdaTAD config + 你自己的 equal-interval 50% / random 50% 复现。
3. **做 densepass bridge official_compat**：在 dense grid 上 bridge 必须 target、decode、pre-NMS、post-NMS 与 official head 对齐；否则 sparse 训练没有意义。
4. **只保留一个主线 bridge**：优先 `native-axis + level_stride decode/radius/range`，因为它最接近官方 stride 语义；`openrange` 只能作为诊断，不应作为最终方法。
5. **用 analyzer 找 42 的真实断点**：如果 target-decode IoU 高但 final proposal IoU 低，问题在训练/feature geometry；如果 pre-NMS 高 post-NMS 低，问题在 NMS/score；如果 target-decode 本身低，问题在 assignment/range/scale。
6. **论文故事不要写“irregular head 自然有效”**，除非恢复到接近 65。更稳的论文路线是：先证明 naive irregular/native bridge 会因 geometry-contract mismatch 崩塌，再提出 geometry-calibrated sparse TAD head，用 target-decode/NMS/score calibration 证据链解释为什么恢复高 IoU。
